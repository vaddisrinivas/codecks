Codecks turns an Android phone, tablet, or Samsung DeX window into a local-first control surface for your Mac.

CONTROL

• Command Deck: large buttons for Finder, Terminal, Spaces, media, screenshots, browser tabs, and reviewed custom actions.
• Bluetooth Trackpad: move, click, drag, scroll, tune sensitivity and haptics, rotate the surface, or use fullscreen.
• Remote Keyboard: send text, snippets, navigation and modifier keys, Enter, and Command+Enter. Short text can use Bluetooth; long or Unicode text can use Mac clipboard paste.
• Clipboard Bridge: manually send text in either direction or enable visible one-way or two-way timed sync with conflict handling.

BUILD

• Rules: local When / If / Then routines with safe templates, test-before-enable behavior, approval where required, and run history.
• Deck Editor: reorder, resize, replace, duplicate, test, and style buttons.
• Command Palette: search actions and Rules without crowding the permanent Deck.
• Optional AI Builder: ask a provider to draft a disabled button, Deck, or Rule, then test and review it before use.

DESK USE

Open Trackpad from a widget, HID notification, NFC tag, Tasker profile, or the exact codecks://trackpad link. An optional restricted lockscreen surface permits pointer input only when Bluetooth HID is already connected. It cannot pair, reconnect, type, run commands, access clipboard, or open settings while locked.

Phone, tablet, landscape, freeform, and DeX layouts adapt automatically. Local JSON backup preserves Deck and Rules while excluding API keys, SSH keys, passwords, and connection secrets.

SAFETY AND PRIVACY

Built-in templates use an allowlist, dangerous shell patterns are blocked, generated actions stay disabled until reviewed, SSH host keys are pinned, and optional AI API keys are encrypted with Android Keystore.

This public beta has no Codecks account, hosted backend, public database, advertising SDK, analytics SDK, or cloud sync. Optional AI requests go directly to the provider selected by the user.
