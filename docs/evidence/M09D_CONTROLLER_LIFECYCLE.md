Three immutable phases:

1. Prior producer-framing source `b835a0f855f93fb32ea3f16f843ee56b86771a20` preserves the reviewed warm-output framing. This append-only first-use-framing source phase changes exactly five evidence paths and is direct-parented by `b835a0f`.
2. C2 artifacts: from clean first-use-framing source, run the exact filtered Gradle command and commit only deterministic sanitized JUnit XML, canonical sanitized log, and artifact manifest; C2 is direct-parented by first-use-framing source.
3. C3 receipt: from clean C2, bind the exact source/C2 topology, bytes, source symbols, test class/methods, tool hashes, JDK command, and compiled production/test tree digests. Commit receipt only.

Each phase requires an exactly clean worktree. Validation compares every C1, C2, and C3 working file byte-for-byte with `git show <phase-commit>:<path>` and requires each phase commit's changed-path closure to equal its declared path set.

Execution is closed to tokenized `$ANDROID_HOME`, `$JAVA_HOME`, `$HOME`, an invocation-owned fresh writable `$GRADLE_USER_HOME`, host-local mutable `$GRADLE_RO_DEP_CACHE`, fixed `PATH`, locale, and empty JVM/Gradle option variables. Each run creates a unique empty home and seeds only the verified Gradle ZIP, checksum receipt, fixed `gradle.properties`, and matching extracted distribution from `$SEED_GRADLE_HOME`; unrelated shared temp caches/state are ignored. Each home's seeded initial and post-build final manifests and each run's timing are separately bound. Gradle version output bypasses the generic whitespace normalizer. Its dedicated UTF-8 path permits no CR or generalized stripping, performs only private-path token replacement, and requires the observed producer framing byte-for-byte: exactly one leading LF, exact core blank lines, one space after each empty option-notice colon, and one final LF. Zero/two leading LFs, zero/two notice spaces, extra LF, or suffix content fail. Its origin and immutability are `NOT_PROVEN` and are not admission provenance. The bound local Gradle binary runs directly with `--offline`; OS-level network denial is `NOT_PROVEN`. Before each run, the focused raw JUnit result is deleted and required lexically absent. Start/end timestamps bracket Gradle; the new result mtime, UTC suite timestamp, and macOS birthtime when available must lie within that interval, and its inode is recorded.
